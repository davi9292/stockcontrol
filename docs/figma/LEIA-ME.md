# Arquivo visual do StockControl para Figma

O arquivo nativo do Figma **StockControl — Wireframes** contém o board vetorial com as cinco telas descritas em [`../figma-wireframe.md`](../figma-wireframe.md): login, produtos, comentários, cadastro de comentário e cadastro de produto.

- [Abrir o arquivo no Figma](https://www.figma.com/design/MgYYgGuXfbxIctQq5RGFBt/StockControl-%E2%80%94-Wireframes?node-id=1-188)
- Cópia vetorial local: [`stockcontrol-wireframes.svg`](stockcontrol-wireframes.svg)

O SVG local é uma cópia de referência para revisão e reimportação. O arquivo do Figma é editável na conta conectada. Use o zoom **Ajustar à seleção** para enquadrar o board e desagrupe os vetores quando precisar editar elementos individualmente.
