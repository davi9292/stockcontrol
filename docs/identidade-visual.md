# Identidade visual StockControl

| Uso | Cor | Aplicação |
|---|---|---|
| Primária | `#145A8D` | Navbar, botões principais e links |
| Secundária | `#18A6A6` | Destaques e ícones |
| Fundo | `#F3F6F8` | Fundo da aplicação |
| Texto | `#20313F` | Texto principal |
| Feedback | sucesso `#198754`, erro `#DC3545`, alerta `#F0AD4E` | Estados e validações |

Fonte principal: `Inter`, com fallback `Arial, sans-serif`. A interface não carrega fonte externa. A marca é fornecida em `assets/img/logo.svg`, com favicon em `assets/img/favicon.svg`; a navbar usa o texto alternativo `StockControl — controle de estoque`.
